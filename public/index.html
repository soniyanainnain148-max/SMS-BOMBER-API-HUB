Docs

  
# blast
GET /api/v1/bomb?key=YOUR_KEY&number=9876543210&count=1

# response
{
  "ok": true,
  "target": "+919876543210",
  "services": 34,
  "accepted": 19,
  "failed": 15,
  "quota": { "used": 1, "limit": 20, "remaining": 19 }
}


  
Parameters:

  
key       required   api key
number    required   10 digit number
cc        optional   country code, default 91
count     optional   rounds 1-5, default 1
services  optional   comma list, default all


  
Aur endpoints:

  
GET /api/v1/services   — live service list
GET /api/v1/health     — gateway health
GET /api/v1/me?key=     — apna quota dekho


  
SMSBOMB API — endpoints third-party gateways ke hain, unke change hone par list update hoti rehti hai.
